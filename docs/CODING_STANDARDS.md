# MemoryLens Coding Standards

## Naming

Classes
- PascalCase

Variables
- camelCase

Files
- snake_case

Folders
- lowercase

------------------------------------

## Widgets

- One widget per file
- Prefer StatelessWidget
- Extract widgets over 100 lines

------------------------------------

## Screens

Maximum 250 lines

------------------------------------

## Constants

Never hardcode:

- colours
- spacing
- strings
- sizes

------------------------------------

## Comments

Explain WHY.

Avoid commenting obvious code.

------------------------------------

## Git

Commit after every successful milestone.
